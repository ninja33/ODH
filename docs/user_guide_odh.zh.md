# 使用说明

[English](user_guide_odh.md) | 中文

本页面向**普通用户**：怎样安装、怎样划词查词、选项页每一栏管什么、怎样制卡。

想写词典脚本请看[词典脚本开发指南](dev_guide_uds.zh.md)；想改扩展本身请看 [ODH 开发指南](dev_guide_odh.zh.md)。

## 1. 安装

| 渠道 | 地址 |
| --- | --- |
| Chrome 应用商店 | [Online Dictionary Helper](https://chrome.google.com/webstore/detail/anki-online-dictionary-he/lppjdajkacanlmpbbcdkccjkdbpllajb?hl=en) |
| Firefox 附加组件 | [Online Dictionary Helper](https://addons.mozilla.org/en-US/firefox/addon/online-dictionary-helper/) |

也可以从源码加载开发版，步骤见 [ODH 开发指南](dev_guide_odh.zh.md)。

> **Firefox 说明**：本项目的当前源码依赖 `chrome.offscreen` 与 `chrome.runtime.getContexts`，Firefox 打包产物未在本仓库验证。Firefox 用户请使用附加组件页面上的版本。

## 2. 基本用法

1. 打开任意网页（含 pdf.js 阅读器里的 PDF）
2. 把鼠标移到想查的词上，然后任选一种：
   - **拖动选中**这个词
   - **双击**这个词
   - 把鼠标悬停在该词上，按**取词热键**（默认 `Shift`）
3. 选词后会在词旁边弹出释义窗口

**词本身是链接时**，拖动选择会触发页面跳转。这种时候用取词热键，或者按住 <kbd>Alt</kbd> 再选。

按 <kbd>Esc</kbd> 关闭弹窗。

## 3. 弹窗里有什么

| 元素 | 说明 |
| --- | --- |
| 单词 | 你选中的原文 |
| 音标 | 来自词典，可能为空 |
| 星级 | 来自词典，可能为空 |
| 发音按钮 | 有音频时显示，点一下朗读 |
| 释义 | 可能有多个词性、多条释义 |
| 例句 | 数量由「例句数量」选项控制 |
| 绿色 **+** | 制卡按钮。未连上 Anki 时显示为禁用态 |
| 原句区 | 可编辑，制卡时提交的是你编辑后的内容 |

## 4. 选项页 - 通用

点浏览器工具栏的扩展图标，选「选项」，或在扩展管理页点「扩展程序选项」。

| 项目 | 作用 |
| --- | --- |
| 开关插件 | 总开关。关掉后不响应划词 |
| 启用鼠标 | 关掉后只有取词热键有效，鼠标划过和双击都不触发 |
| 取词热键 | `Off` / `Shift` / `Ctrl` / `Alt` 四选一。选 `Off` 表示不用热键 |
| 词典名称 | 从已加载的词典里选一本 |
| 单语双语 | 双语时同时显示原文释义与译文；单语只显示原文 |
| 音频偏好 | 有多个音源时制卡用哪一个 |
| 原句数量 | 从页面上下文提取几句作为原句，`1`–`3` |
| 例句数量 | 词典提供的例句最多显示几条，`0`–`2` |

## 5. 选项页 - 输出（Anki）

这一栏的**配置面板**按服务类型显示，但「数据导出」下拉和状态行始终可见。

**第一步：选服务。** 在「数据导出」下拉里选 `Ankiconnect`。选 `None` 时只隐藏下面的配置面板，下拉本身和状态行仍在。

选好 `Ankiconnect` 后，URL 与连接面板出现：

| 项目 | 作用 |
| --- | --- |
| 连接地址 | AnkiConnect 的地址，默认 `http://127.0.0.1:8765` |
| 连接按钮 | 点它测试连接 |

连接状态显示在「数据导出」右侧的状态行里，有三种：`连接中...`、`已连接:<版本>`、`未连接`。**连接失败时状态行变成「未连接」，但它仍然可见**——那是你判断问题的唯一反馈。

**连接成功后才出现**牌组、模板与字段映射：

| 项目 | 作用 |
| --- | --- |
| 牌组名称 | 卡片进哪个牌组 |
| 模板名称 | 用哪个笔记模板 |
| 单词词组 / 发音音标 / 单一释义 / 全部释义 | 字段映射，把对应的内容放进模板字段 |
| 原句笔记 / 额外信息 / 来源网址 / 音频文件 | 其余字段映射 |
| 笔记标签 | 卡片标签，多个用空格分隔 |
| 重复制卡 | 是否允许同一张卡重复添加 |

上表就是全部字段映射。留空的映射表示不写入该字段。

> 旧版配置里的 `ankiweb` 服务已移除，会显示为未选服务。

## 6. 选项页 - 脚本

| 区域 | 作用 |
| --- | --- |
| 自选脚本 | 填你自己脚本的地址，点「加载脚本」加载。地址规则见[词典脚本开发指南](dev_guide_uds.zh.md)第 4 节 |
| 系统脚本 | 扩展内置的脚本列表。每行有「激活」与「云端」两个勾选框 |
| 激活列 | 勾上 = 加载这本词典 |
| 云端列 | 勾上 = 从 GitHub 上的 `master` 分支取，而不是用扩展自带的副本 |

数组里的第一行（内置词典）两个勾选框固定不可改，它是保底词典。

> **改脚本内容后「加载脚本」不会重新取文本。** 扩展只在脚本名列表发生变化时重新加载。要让它重新拉取，改动一下输入框里的地址再改回来，或在扩展管理页点一次「重新加载」。

## 7. 制卡

**前置**：装好 [Anki](https://apps.ankiweb.net/) 与 [AnkiConnect](https://github.com/FooSoft/anki-connect) 插件，并保持 Anki 运行。在选项页配好服务、牌组、模板与字段映射。

流程：

1. 划词，等弹窗出现
2. 确认释义与音标显示正确
3. 需要的话，在弹窗底部的原句区编辑句子
4. 点某条释义右上角的绿色 **+**
5. 按钮会短暂变成加载图标，成功显示对勾、失败显示叉，一秒后复原

**绿色 + 只出现一次，对应一条释义。** 想加整条词条的全部释义，用「全部释义」映射；单条用「单一释义」映射。

## 8. 常见问题

**划词没有弹窗**

- 扩展被关掉了（点工具栏图标看总开关，或按扩展快捷键 `Alt+Q` 切换）
- 「启用鼠标」被关掉，而你又没按热键
- 选中内容被判定为无效元素（在某些 `iframe`、`canvas`、浏览器内部页面上取词不生效）
- 词本身是链接且你用了拖动选择——改用热键
- 扩展刚更新过，而当前页面是在更新前打开的：刷新页面

**Anki 显示「未连接」**

- Anki 没开，或 AnkiConnect 插件没装
- AnkiConnect 的端口不是 `8765`，或地址填错
- 防火墙拦了本地回环端口

**制卡失败显示叉**

- 牌组或模板名与 Anki 里实际的不一致
- 字段映射与模板字段对不上
- 不允许重复制卡，而这张卡已存在——把「重复制卡」改成允许，或删掉已有卡片

**查不到词**

- 当前词典没有收录这个词——换一本词典试试
- 那本词典的脚本坏了（站点改版），换一本
- 内置词典数据缺失时内置词典查不到任何词，但外部词典脚本不受影响

**弹窗样式错乱**

- 某些站点有严格的 CSP，会拦下词典自带的样式。这是已知限制
- 词典脚本的 CSS 若用了 `#id` 或 `body` 选择器会被过滤掉，属预期行为，见[词典脚本开发指南](dev_guide_uds.zh.md)第 9 节

## 9. 已知限制

- 最低 Chrome 版本 116
- Firefox 打包与运行未在本仓库验证，请使用附加组件页面的版本
- 词典脚本无法设置请求头（含 `Referer`），部分词典站点会因此拒绝
- 没有脚本级权限声明：加载第三方脚本前请自行确认来源可信
- `api.fetch` 的 6 秒上限不可配置
